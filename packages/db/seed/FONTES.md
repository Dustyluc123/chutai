# Fontes dos dados dos temas

Cada personagem dos temas com pessoas reais tem os dados conferidos nas fontes abaixo
(Wikipédia em português e, quando a Wikipédia não traz o dado, o Wikidata ligado ao artigo
ou uma fonte oficial). Os dados valem para o mês indicado em `dataUpdatedAt` de cada tema.

Regras seguidas: só adultos; só fatos públicos e neutros (nada de religião, política,
orientação sexual, saúde, relacionamentos, polêmicas ou processos); quem não teve um dado
confirmado ficou fora do tema.
